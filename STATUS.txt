23 Nov  E3b, the lock screen on its own Windows desktop, like the Windows sign-in screen (built 19-22 Nov; decided 13 Nov
              as needed before the Phase 0 build). Branch feature/e3b-own-desktop, not merged yet. Before, the lock
              screen was an always-on-top window on the normal desktop: a Windows system dialog could sit above it, and
              a window that kept the focus let keys through. Now a locked PC shows a second desktop that holds only the
              lock screen. The customer's programs and windows stay on the normal desktop, out of sight and out of reach
              of the keyboard and mouse. Code: pc/Cafe.Agent/Program.cs (LockDesktop, LockScreen, KeyBlocker).
              1 The PC program makes a desktop named CafeLock-<its process number> and runs the lock screen there on its
                own thread. Locking gives that desktop the screen; unlocking gives the normal desktop back. The thread is
                made by Windows itself, moved first, then started as STA: a .NET-made STA thread could not move (error
                170), and without STA a click sent by UI Automation froze the lock screen (both measured).
              2 While locked, the lock screen's 0.5 s timer asks Windows to give its desktop the screen, every time. Any
                program can switch the screen to the normal desktop (measured); the lock screen has it again within
                0.5 s. Asking while it already has the screen does nothing (measured: 0.02 ms, no lost key).
              3 The desktop is made with rights for Windows itself, admins and the maker's own handle only. Another
                program of the Customer is refused for everything (measured as a standard user). With the rights Windows
                gives by itself, such a program could open the desktop fully (measured).

                its own desktop (measured). Left on the normal desktop, it let Ctrl+Shift+Esc open Task Manager on the
                lock screen's desktop and Win+U open Settings (measured).
              5 A restarted program (the watchdog brings a killed one back) makes a new desktop and gives it the screen.
