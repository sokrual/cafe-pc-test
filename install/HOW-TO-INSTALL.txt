SHINZX CAFE SOFTWARE - HOW TO INSTALL

You need: the admin password of each PC. Do the counter PC first.
If something goes wrong, send a photo of the screen and the file install-log.txt
(it is next to INSTALL-PC or INSTALL-ADMIN) on Discord to the person who gave you this software.

A. THE COUNTER PC (once)
The counter PC's Windows account must have a password or PIN; otherwise the 10-minute idle lock protects nothing.
1. Make sure this PC always gets the same network address.
   In the router's settings this is called "address reservation" or "static IP".
   If you are not sure how, ask the person who set up your internet.
2. Double-click INSTALL-ADMIN. Click "Yes" when Windows asks for permission.
3. It shows this PC's address (for example 192.168.1.10). Write it down.
4. Open http://127.0.0.1:3000 in the browser. This sets up the internet filter.
   Where it asks about the "DNS server", choose "All interfaces" and port 53.
   Choose a password and write it down.
   Then open Settings, then General settings, and set "Query logs retention" to 180 days (4320 hours).
   The law asks a cyber cafe to keep a list of the websites used for 180 days.
5. A folder "for-gaming-PCs" appears next to INSTALL-ADMIN. Copy what is inside it,
   and each PC's key file, into the install folder you take to the gaming PCs.

B. EACH GAMING PC (two short visits)
Do ONE gaming PC first and use it for a day. If all is well, do the others.

1. Double-click INSTALL-PC. Type the counter PC's address when it asks.
   The PC restarts and opens the "Customer" account by itself. There is no lock screen yet.
2. In the Customer account: install Discord, put the game shortcuts on the desktop,
   and open the mouse, keyboard and headset apps once.
   Do NOT sign in to Discord, Steam or any other app.
3. Double-click INSTALL-PC again. It asks for the admin password.
   It saves a clean copy of the Customer account and restarts. Now the lock screen is on.

When a customer logs out, the PC closes everything they opened, removes their files and all
their app logins (Discord, Steam, browsers, Epic, Riot), and puts the clean copy back.
This takes a few seconds. Nobody can log in until it is done.

To change the Customer account later (a new game shortcut, a Discord update):
log in on the lock screen with your own phone number, open C:\Program Files\ShinzxCafe,
double-click SETUP-MODE, then do steps B2 and B3 again.

A new game: right-click it, choose "Run as administrator" and type the admin password. Do this once.
It lets the game's anti-cheat set itself up. After that customers play it normally.

To take the software off: double-click UNINSTALL-PC on a gaming PC, or UNINSTALL-ADMIN on the counter PC.

Also on every PC: set a password for the BIOS (the settings screen that opens before Windows starts)
and turn off "boot from USB" there. Then nobody can start the PC from a USB stick.
